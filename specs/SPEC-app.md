# Spec 2: 倒排索引 → 字根反查 + 谜材检索应用

## 概述

基于生成的倒排索引 JSON 数据，提供桌面端字根反查工具。用户输入字根（偏旁、笔画等组件），系统返回同时包含所有指定字根的汉字或谜材词语。

## 技术栈

- **运行时**: Electron (Node.js)
- **前端**: 纯 HTML/CSS/JS（无框架），fetch API
- **后端**: Electron 主进程内嵌 HTTP 服务
- **数据存储**: 倒排索引 JSON 文件 + 谜材 JSON 文件

## 项目结构

```
chaizi/
├── app/                          # Electron 应用
│   ├── package.json              # Electron 依赖配置
│   ├── main.js                   # 主进程：HTTP 服务 + 谜材 CRUD API
│   └── index.html                # 前端：字根反查 + 谜材管理
├── caizi-data/                   # 谜材持久化（每个分组一个 .json）
│   └── {分组名}.json
├── data.json                     # 合并的索引数据（前端加载）
├── all.json / jt.json / ft.json  # 独立索引数据（前端备用加载）
├── strokes.json                  # 笔画数映射
├── gen_json.py                   # 生成索引 JSON
├── invert_index.py               # 构建倒排索引
└── recursive_decompose.py        # 递归拆字
```

## 数据格式

### 倒排索引 JSON (`all.json` / `jt.json` / `ft.json`)

```json
{
  "一": ["丁", "七", "万", "丈", "三", "上", "下", ...],
  "口": ["中", "史", "只", "叭", "叮", "叹", ...],
  "木": ["术", "本", "未", "末", "札", ...]
}
```

- Key: 组件（偏旁、笔画、部件）
- Value: 包含该组件的所有汉字数组（按笔画数升序排列）

### 笔画数映射 (`strokes.json`)

```json
{
  "一": 1, "丁": 2, "七": 2, "万": 3,
  "龍": 16, "㗅": 99999
}
```

- 未知笔画数的字标记为 `99999`

### 谜材数据 (`caizi-data/{分组名}.json`)

```json
["春风化雨", "刻舟求剑", "守株待兔", ...]
```

## 功能模块

### F1: 单字检索

**输入**: 一个或多个字根（组件）
- 文本框直接输入，按单个字符拆分（空格等分隔符被忽略）
- 偏旁笔画面板点选，组件直接追加到输入框

**处理**:
1. 从输入框提取所有不重复的组件字符
2. 在当前模式的倒排索引中，查找每个组件对应的汉字集合
3. 取所有组件汉字集合的**交集**
4. 结果按笔画数升序排序

**输出**: 匹配的汉字列表，最多显示 2000 个

**示例**:
```
输入: 人 王
匹配: 珍(9画)  全(6画) 呈(7画) ...
解释: "珍"的拆分包含"人"和"王"两个组件
```

### F2: 偏旁笔画面板

**功能**: 可展开的网格面板，列出所有可用组件
- 共 2572 个组件（全部模式）
- 支持搜索过滤
- 点击组件可切换选中状态，与输入框双向同步

### F3: 模式切换

三种检索模式，通过 Tab 切换：

| 模式 | 说明 | 数据源 | 组件数 |
|------|------|--------|--------|
| 全部 | 简体 + 繁体 | `all.json` | 2572 |
| 简体 | 仅简体字 | `jt.json` | 2165 |
| 繁体 | 仅繁体字 | `ft.json` | 2359 |

### F4: 谜材检索

**目的**: 根据字根在用户导入的谜材（词语、成语、诗词等）中检索匹配项

**输入**: 与单字检索相同（字根输入）
**筛选**: 仅在用户勾选的谜材分组中检索

**处理**:
1. 先用单字检索逻辑得到匹配的汉字集合
2. 遍历选中分组中的所有谜材词语
3. 对每个词语，检查是否包含匹配集合中的任一汉字
4. 匹配的汉字在结果中红色高亮
5. 结果按匹配字的最小笔画数排序

**输出**: 匹配的谜材词语列表，标注所属分组

**示例**:
```
字根输入: 口 木
谜材分组: [成语, 奶茶小料]
结果: 呆(成语)  杏(成语)  桂圆(奶茶小料)  ...
```

### F5: 谜材管理

**导入方式**:
1. **手动输入**: 在文本框输入词语，支持换行、逗号（中英文）、顿号、空格分隔
2. **文件导入**: 选择 `.txt` 文件（每行一条）
3. **JSON 导入**: 导入之前导出的 JSON 文件，合并到现有数据

**持久化**:
- 每个谜材分组存储为 `caizi-data/{分组名}.json` 文件
- 通过后端 API (`/api/caizi/save`, `/api/caizi/delete`) 读写

**分组操作**:
- 创建新分组（导入时指定分组名称）
- 全选/取消全选分组
- 删除分组
- 同名分组导入时提示覆盖确认

**导出**:
- 点击「导出全部」→ 下载所有分组合并的 JSON 文件

### F6: 结果排序

所有检索结果按笔画数升序排列：
- 单字检索：直接按字的笔画数排序
- 多字根交集：交集结果按笔画数排序
- 谜材检索：按匹配字中最少笔画数排序

笔画数来源：前端加载 `strokes.json` 中的 `strokeMap`
- 已知笔画数：正常排序
- 未知笔画数（99999）：排在最后

## 后端 API

Electron 主进程内嵌 HTTP 服务，端口自动分配。

### 静态文件

优先从 `app/` 目录查找，回退到项目根目录。

| 路径 | 说明 |
|------|------|
| `/` | `app/index.html` |
| `/data.json` | 合并索引数据 |
| `/jt.json` `/ft.json` | 独立索引数据 |
| `/strokes.json` | 笔画数映射 |

### 谜材 CRUD

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/caizi` | 获取所有分组 `{名: [...]}` |
| GET | `/api/caizi?group=xxx` | 获取指定分组 |
| POST | `/api/caizi/save` | 保存分组 `{"name":"xxx","items":[...]}` |
| POST | `/api/caizi/delete` | 删除分组 `{"name":"xxx"}` |

### 安全

- 静态文件服务限制在 `app/` 和项目根目录内（路径遍历防护）
- 分组名自动清理特殊字符

## 前端初始化

启动时并行加载 5 个数据源：
```javascript
const [allData, jtData, ftData, strokesData, caiziData] = await Promise.all([
  fetch('data.json').then(r => r.json()),     // 合并索引
  fetch('jt.json').then(r => r.json()),         // 简体索引
  fetch('ft.json').then(r => r.json()),         // 繁体索引
  fetch('strokes.json').then(r => r.json()),    // 笔画映射
  fetch('/api/caizi').then(r => r.json()),      // 谜材数据
]);
```
